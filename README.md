# 🌤 Telegram Бот Погоды — Инструкция по запуску

## Шаг 1 — Получи Telegram токен
1. Открой Telegram, найди **@BotFather**
2. Напиши `/newbot`
3. Придумай имя и username боту
4. Скопируй токен вида `123456:ABC-DEF...`

## Шаг 2 — Получи API ключ погоды (бесплатно)
1. Зайди на https://openweathermap.org/api
2. Зарегистрируйся (бесплатно)
3. Перейди в **API keys** → скопируй ключ
4. ⚠️ Ключ активируется через ~10 минут после регистрации

## Шаг 3 — Вставь ключи в bot.py
Открой `bot.py` и замени:
```python
TELEGRAM_TOKEN = "ВАШ_TELEGRAM_BOT_TOKEN"
WEATHER_API_KEY = "ВАШ_OPENWEATHERMAP_API_KEY"
```

## Шаг 4 — Установи зависимости
```bash
pip install -r requirements.txt
```

## Шаг 5 — Запусти бота
```bash
python bot.py
```

## Использование бота
| Команда | Описание |
|---------|----------|
| `/start` | Начать работу |
| `/setcity` | Задать свой город |
| `/settime` | Выбрать время ежедневной рассылки (например 07:30) |
| `/weather` | Узнать погоду прямо сейчас |
| `/status` | Посмотреть настройки |
